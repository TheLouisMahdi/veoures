Privacy & contribution limits

The shared organism is open to visitors without an account. Your accepted changes become part of a public artwork.

What is saved

Tool type, position, accepted time, optional public display name and mutation parameters are saved in the shared database. Earlier written traces remain readable in the writing corner and inspector. New contributions grow anatomical organs. Their original values remain available in the public event API. Please do not share private information. Browser identity and network hashes are excluded from public events.

Your contribution session

The hosted edition uses a random, secure HttpOnly cookie for up to 30 days. It allows four accepted changes per contributor session per personal 24-hour day, with a randomly assigned opening time shown in the controls and safe retries without duplicate changes. Previews and cancellation do not use quota. Clearing cookies starts a different session; this is an anonymous art project, not a verified identity service.

A daily one-way network hash supports abuse limits without storing raw IP addresses. Shared networks allow up to 100 accepted changes and 20 newly issued sessions per UTC day, with a short pause between writes. These limits can affect visitors on the same shared connection.

Optional contributor ranking and recovery

Public ranking is off until you choose it. A random public contributor ID groups accepted biological events independently of your display name; two people choosing the same name remain separate. Names are unverified. The leaderboard includes accepted totals, deterministic anatomical impact, evolutionary influence, public regional history and collection milestones. Older name-only credits are unverified and excluded. You can opt out through Your contributor identity inside Ranks; the accepted public event record and any name submitted with it remain part of the artwork.

A recovery key is optional and shown once. Only its SHA-256 hash is stored by the server. Anyone possessing the key can restore your contributor on a different browser, sharing the same quota and public preferences. Keep it private. Creating a new key invalidates the previous key. Without a key, clearing or expiring the 30-day session can lose access to that identity. Private cookie hashes, recovery hashes and network data are never included in public profiles.

Browser preferences and sound

Local storage remembers this browser's demo state and connection identity. The static local demo never uploads its changes. Sound starts off. Ambient files load only after you turn it on; the paired heartbeat is generated locally with Web Audio after the same explicit action. No microphone is used. No analytics, advertising scripts or external fonts are included by this application.

Artwork and availability

Legacy surface scars, mass traces and written traces dissolve over four hours from acceptance. New biological mass matures over 8–24 hours, eyes over 24–48 hours, and limbs over 36–72 hours. These organs persist as anatomy; bounded tissue renewal keeps growth stable. This is visual ageing, not deletion: accepted records persist across reloads and deployments. Every 414 accepted changes records a form for the digital-art collection. Its portrait and named contributor credits can be kept. The body continues changing. There is no lifetime event cap in the application; anatomical density and spacing rules can reject crowded placements without consuming quota. The latest 30 traces appear in the inspector. Names are self-chosen public credits, not verified identities.
